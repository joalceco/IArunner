# Quick Start Guide

## Get Started in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Game
```bash
npm run dev
```

### 3. Play!
Open your browser to http://localhost:5173 and start playing!

## Controls

### Desktop
- **↑** or **W** or **Space** - Jump over obstacles
- **↓** or **S** - Slide under obstacles
- **→** or **D** - Dash forward
- **ESC** - Pause game

### Mobile
- **Swipe Up** - Jump
- **Swipe Down** - Slide
- **Swipe Right** - Dash
- **Tap** - Jump

## Game Objective

- Run as far as possible through the office corridor
- Avoid obstacles (desks, printers, papers, flying memos)
- Collect paperclips (📎) to purchase upgrades
- Reach milestones to unlock the upgrade shop
- Survive as long as you can!

## Upgrades Available

1. **Magnet** - Auto-collect nearby paperclips
2. **Energy Drink** - Extra lives
3. **Coffee Boost** - Temporary speed boost
4. **Keyboard Armor** - Reduce obstacle damage
5. **Roller-chair Wheels** - Short gliding ability
6. **Headphones** - Temporary invincibility

## Additional Commands

```bash
npm run lint          # Check code quality

```

## Embedding the Game

After building (`npm run build`), you can embed the game:

```html
<iframe 
  src="path/to/dist/index.html" 
  width="800" 
  height="400" 
  frameborder="0">
</iframe>
```
